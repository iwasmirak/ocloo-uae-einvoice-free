# Ocloo UAE E-Invoicing (PINT-AE) — free trial, Odoo 19.0

This branch holds the `mirak_uae_einvoice` module for **Odoo 19.0**.

* PINT-AE 1.0.4 (UBL 2.1) invoices and credit notes, official Schematron validation.
* Vendor bill import, readiness checker, dashboard, English and Arabic.
* Simulation provider to test the whole flow.
* **Trial limits:** 15 documents in total, no REST connector to a real ASP.

## Install

1. Copy the `mirak_uae_einvoice` folder into your addons path and restart Odoo.
2. Update the apps list and install *Ocloo UAE E-Invoicing (PINT-AE) — Free Trial*.
3. Settings → UAE E-Invoicing: TRN, Peppol ID, trade licence, emirate, mandate date.
4. Choose the simulation provider, run the readiness checker, post and send a test invoice.

The full edition (unlimited documents and the configurable REST connector) is distributed
separately. See the [main branch](../../tree/main) for the complete description.

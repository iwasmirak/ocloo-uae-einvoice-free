Requirements

  • Odoo 19.0 — Community or Enterprise, with the Accounting app.
  • Python lxml and requests.
  • Optional saxonche for the official Schematron validation.
  • An Accredited Service Provider contract for live Peppol and FTA exchange (full edition).

Good to know

  • The trial edition is limited to 15 documents in total and works with the simulation provider only. The REST connector to a real Accredited Service Provider is part of the full edition.
  • The module is not an Accredited Service Provider and does not replace one.
  • The REST connector posts UBL XML and reads JSON; unusual provider APIs may need a small adapter.
  • Trial and full editions share the same models: install them in separate databases.
